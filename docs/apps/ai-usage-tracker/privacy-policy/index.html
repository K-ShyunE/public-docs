AI Usage Tracker 개인정보처리방침

시행일 및 최종 수정일: 2026년 8월 28일

AI Usage Tracker(이하 “확장 프로그램”)는 사용자의 개인정보를 중요하게 생각합니다. 이 방침은 확장 프로그램이 어떤 데이터를 처리하고 그 데이터를 어떻게 사용하는지 설명합니다.

1. 처리하는 데이터

확장 프로그램은 기능 제공을 위해 다음 데이터를 사용자의 브라우저 안에서 처리합니다.

  • 인증 정보: 현재 로그인된 ChatGPT 세션의 액세스 토큰을 일시적으로 사용하여 ChatGPT의 공식 사용량 API를 호출합니다.
  • 사용량 정보: Codex의 5시간 및 주간 사용률, 남은 비율, 초기화 시각, 플랜 종류와 마지막 갱신 시각을 처리합니다.
  • 페이지 인터페이스 정보: 위젯을 표시하고 플랜을 판별하기 위해 ChatGPT 페이지의 사이드바 구조, 프로필 버튼의 플랜 관련 표시 및 모델 표시를 확인할 수 있습니다.
  • 사용자 동작 신호: 사용량을 적시에 갱신하기 위해 메시지 전송 버튼 클릭 또는 Enter 키 입력 발생 여부를 감지합니다. 입력한 키의 내용이나 메시지 내용은 수집하지 않습니다.

확장 프로그램은 사용자의 대화 내용, 프롬프트, ChatGPT 응답, 비밀번호, 결제 정보, 건강 정보 또는 위치 정보를 수집하거나 저장하지 않습니다.

2. 데이터 이용 목적

처리된 데이터는 Codex 사용량과 초기화 시각을 확장 프로그램 팝업, ChatGPT 사이드바 위젯 및 브라우저 도구 모음 배지에 표시하는 목적으로만 사용됩니다.

3. 데이터 저장 및 보관

  • 사용률, 초기화 시각, 플랜 종류, 연결 상태 및 마지막 갱신 시각은 사용자의 기기에 있는 chrome.storage.local에 저장됩니다.
  • 액세스 토큰, 프로필 원문 및 메시지 내용은 chrome.storage.local에 저장되지 않습니다.
  • 로컬 데이터는 새로운 사용량 정보로 갱신되며, 확장 프로그램을 삭제하거나 Chrome의 확장 프로그램 데이터를 삭제하면 제거됩니다.

4. 데이터 전송 및 공유

  • 확장 프로그램은 개발자가 운영하는 서버로 사용자 데이터를 전송하지 않습니다.
  • 인증 정보는 사용량 조회를 위해 사용자의 브라우저에서 현재 로그인된 ChatGPT의 공식 HTTPS 엔드포인트로만 전송됩니다.
  • 사용자 데이터를 판매하거나 광고, 신용도 판단 또는 대출 목적으로 사용하지 않습니다.
  • 위 ChatGPT 공식 API 요청을 제외하고 사용자 데이터를 다른 제3자에게 제공하거나 공유하지 않습니다.

5. 권한 사용

  • storage: 사용량과 갱신 상태를 사용자 기기에 저장하고 팝업, 위젯 및 배지 사이에서 동기화하는 데 사용합니다.
  • chatgpt.com 호스트 접근: ChatGPT 페이지에 위젯을 표시하고 로그인된 사용자의 공식 사용량 API를 조회하는 데 사용합니다.

6. Chrome 웹 스토어 제한적 사용 준수

확장 프로그램이 사용자 데이터에 접근하거나 이를 사용하는 행위는 확장 프로그램의 단일 목적 기능을 제공하는 데 필요한 범위로 제한됩니다. 사용자 데이터는 관련 없는 목적으로 사용하거나 전송하지 않으며, 맞춤형 광고에 사용하지 않고 법률상 허용된 예외를 제외하고 사람이 열람하도록 하지 않습니다.

7. 방침 변경

확장 프로그램의 기능이나 데이터 처리 방식이 변경되면 이 방침을 갱신하고 상단의 최종 수정일을 변경합니다. 중요한 변경 사항은 확장 프로그램 또는 배포 페이지를 통해 안내할 수 있습니다.

8. 문의

개인정보처리방침에 관한 문의는 공개 문서 저장소의 문의 페이지를 통해 전달할 수 있습니다. 공개 문의에는 인증 정보나 그 밖의 민감한 정보를 포함하지 마십시오.
